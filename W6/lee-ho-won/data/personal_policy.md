# 개인 생활 규칙 문서

## 1. 수업 보강 관리

### 1-1. 녹화강의 링크 관리
- 결석 또는 공휴일로 인해 보강이 필요한 경우 교수님께 녹화강의 링크를 메일로 전달한다.
- 메일에는 수업명, 날짜, 녹화강의 링크를 포함한다.
- 여러 과목의 보강 링크가 있는 경우 과목별로 구분해서 작성한다.

### 1-2. 보강 횟수 확인
- 수업별 보강 가능 횟수는 강의계획서 또는 교수님 공지를 기준으로 확인한다.
- 보강 횟수가 애매한 경우 교수님 또는 조교에게 메일로 문의한다.

---

## 2. 메일 작성 규칙

### 2-1. 교수님께 메일 보낼 때
- 첫 문장은 정중한 인사로 시작한다.
- 본문에는 본인 소속, 이름, 요청 사항을 명확히 작성한다.
- 마지막에는 감사 인사를 포함한다.
- 너무 긴 문장보다는 짧고 명확한 문장을 사용한다.

### 2-2. 외부 담당자에게 메일 보낼 때
- 요청받은 자료를 첨부했는지 확인한다.
- 첨부 파일명을 본문에 언급한다.
- 연락 가능한 이메일 또는 전화번호를 함께 적는다.

---

## 3. 논문 제출 체크리스트

### 3-1. 제출 전 확인 사항
- 제목, 저자명, 소속 정보를 확인한다.
- Figure 번호와 본문 참조 번호가 일치하는지 확인한다.
- Table 번호와 본문 참조 번호가 일치하는지 확인한다.
- Reference 중복 여부를 확인한다.
- 약어는 첫 등장 시 full name과 abbreviation을 함께 작성한다.
- 캡션 문체와 논문 전체 문체가 일관적인지 확인한다.

---

## 4. 발표 준비 체크리스트

### 4-1. 발표 전 확인 사항
- 발표 자료의 전체 흐름이 자연스러운지 확인한다.
- 실험 결과를 먼저 보여주기 전에 왜 이 분석이 필요한지 설명한다.
- 그래프의 축 이름과 단위를 확인한다.
- 발표 대본이 슬라이드 순서와 맞는지 확인한다.
- 예상 질문과 답변을 미리 정리한다.
