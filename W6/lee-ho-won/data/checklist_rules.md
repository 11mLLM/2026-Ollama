# 체크리스트 생성 규칙

이 문서는 Local Life Assistant가 사용자의 상황을 바탕으로 체크리스트를 만들 때 참고하는 규칙이다.

---

## 1. 기본 원칙

### 1-1. 체크리스트 작성 기준

* 사용자가 바로 실행할 수 있는 행동 중심으로 작성한다.
* 추상적인 표현보다 구체적인 행동을 우선한다.
* 중요한 항목을 위쪽에 배치한다.
* 항목은 너무 길지 않게 작성한다.
* 사용자가 입력하지 않은 세부 조건은 임의로 단정하지 않는다.
* 필요한 경우 “확인 필요” 또는 “상황에 따라 조정”이라고 표시한다.

### 1-2. 출력 형식

체크리스트는 기본적으로 아래 형식을 따른다.

```text
[체크리스트 제목]

1. 핵심 준비 항목
- [ ] 항목
- [ ] 항목

2. 확인 항목
- [ ] 항목
- [ ] 항목

3. 마무리 항목
- [ ] 항목
- [ ] 항목

요약:
...
```

## 2. 메일 발송 전 체크리스트

### 2-1. 교수님께 메일 보내기 전

* [ ] 첫 문장이 정중한 인사로 시작하는지 확인
* [ ] 본인 이름과 소속 또는 수업명을 적었는지 확인
* [ ] 메일을 보내는 목적이 명확한지 확인
* [ ] 링크 또는 자료를 전달하는 경우 누락되지 않았는지 확인
* [ ] 첨부파일이 있는 경우 실제로 첨부했는지 확인
* [ ] 요청 사항이 너무 모호하지 않은지 확인
* [ ] 마지막에 감사 인사를 포함했는지 확인
* [ ] 제목만 보고도 메일 목적이 드러나는지 확인

### 2-2. 외부 담당자에게 메일 보내기 전

* [ ] 상대방 이름 또는 직함이 맞는지 확인
* [ ] 요청받은 자료가 정확히 포함되었는지 확인
* [ ] 첨부파일명과 본문 내용이 일치하는지 확인
* [ ] 연락 가능한 이메일 또는 전화번호가 필요한 경우 포함했는지 확인
* [ ] 표현이 지나치게 캐주얼하지 않은지 확인

---

## 3. 논문 제출 전 체크리스트

### 3-1. 문서 구성 확인

* [ ] 제목, 저자명, 소속 정보 확인
* [ ] Abstract와 Introduction의 핵심 메시지 일관성 확인
* [ ] Method, Experiment, Conclusion 흐름 확인
* [ ] Figure 번호와 본문 참조 번호 일치 여부 확인
* [ ] Table 번호와 본문 참조 번호 일치 여부 확인
* [ ] 캡션 문체와 전체 논문 문체 일관성 확인

### 3-2. 표현 및 형식 확인

* [ ] 약어 첫 등장 시 full name과 abbreviation을 함께 작성했는지 확인
* [ ] 동일 용어가 논문 전체에서 일관되게 사용되는지 확인
* [ ] 불필요하게 긴 문장이 없는지 확인
* [ ] 수치, 단위, 데이터셋 이름 표기 확인
* [ ] Reference 중복 여부 확인
* [ ] Reference 형식이 요구 양식과 맞는지 확인

### 3-3. 제출 직전 확인

* [ ] 최종 파일명이 명확한지 확인
* [ ] PDF 변환 후 그림과 표가 깨지지 않았는지 확인
* [ ] 제출 사이트 요구 형식 확인
* [ ] 마감 시간 확인
* [ ] 공동저자 또는 지도교수님 검토 여부 확인

---

## 4. 발표 준비 체크리스트

### 4-1. 발표 자료 구성

* [ ] 발표 목적이 첫 부분에서 명확히 드러나는지 확인
* [ ] 배경 → 문제점 → 해결 방법 → 결과 → 결론 흐름 확인
* [ ] 슬라이드마다 핵심 메시지가 하나씩 있는지 확인
* [ ] 실험 결과를 보여주기 전에 왜 필요한 분석인지 설명했는지 확인
* [ ] 마지막 슬라이드에 핵심 기여 또는 결론이 정리되어 있는지 확인

### 4-2. 시각 자료 확인

* [ ] 그래프 축 이름과 단위 확인
* [ ] 표의 수치와 본문 설명이 일치하는지 확인
* [ ] 그림 해상도가 충분한지 확인
* [ ] 색상 대비가 발표 화면에서 잘 보이는지 확인
* [ ] 불필요하게 작은 글씨가 없는지 확인

### 4-3. 발표 연습

* [ ] 발표 대본이 슬라이드 순서와 맞는지 확인
* [ ] 제한 시간 안에 발표 가능한지 확인
* [ ] 예상 질문과 답변 정리
* [ ] 핵심 실험 결과에 대한 설명 연습
* [ ] 첫 문장과 마지막 문장을 자연스럽게 말할 수 있는지 확인

---

## 5. 수업 및 과제 관리 체크리스트

### 5-1. 수업 보강 관련

* [ ] 보강 대상 날짜 확인
* [ ] 녹화강의 링크가 정확한지 확인
* [ ] 과목명과 날짜를 구분해서 정리했는지 확인
* [ ] 교수님 또는 조교에게 전달해야 하는 경우 메일 제목 확인
* [ ] 보강 가능 횟수 또는 인정 기준 확인

### 5-2. 과제 제출 전

* [ ] 과제 요구사항을 다시 확인
* [ ] 파일 형식이 맞는지 확인
* [ ] 파일명이 명확한지 확인
* [ ] 제출 사이트 또는 이메일 주소 확인
* [ ] 제출 후 정상 업로드 여부 확인

---

## 6. 요약 작성 규칙

체크리스트 마지막에는 한두 문장으로 요약을 추가한다.

예시:

* “가장 중요한 것은 제출 형식과 마감 시간을 먼저 확인하는 것입니다.”
* “메일 발송 전에는 목적, 첨부 여부, 감사 인사를 마지막으로 확인하는 것이 좋습니다.”
* “발표 준비에서는 전체 흐름과 예상 질문 대비가 핵심입니다.”
