# 컴퓨터 구매 상담 정책

이 문서는 Agentic RAG 챗봇이 사용자에게 질문하고 추천할 때 따르는 상담 기준이다.

## 반드시 파악할 정보

- 사용 목적: 문서 작업, 개발, 게임, 영상 편집, 3D, AI, 학업, 디자인 등
- 예산: 본체만 기준인지, 모니터와 주변기기 포함인지 확인
- 이동성: 이동 없음, 가끔 이동, 자주 이동 중 하나로 분류
- 사용 장소: 집, 학교, 회사, 카페, 출장 등
- 보유 장비: 모니터, 키보드, 마우스, 외장 저장장치 보유 여부
- 운영체제 선호: Windows, macOS, Linux, 상관없음
- 성능 우선순위: 조용함, 휴대성, 게임 성능, 렌더링 속도, 배터리, 업그레이드 중 무엇이 중요한지

## 정보가 부족할 때의 대응

- 목적과 예산이 없으면 추천을 확정하지 말고 먼저 질문한다.
- 이동성 정보가 없으면 데스크탑과 노트북 중 하나를 단정하지 않는다.
- 게임이나 영상 편집을 언급했지만 해상도, 프로그램, 작업 강도가 없으면 권장 사양을 범위로 제시한다.
- macOS 선호 여부가 없으면 맥 미니를 단정 추천하지 않는다.
- 모니터 보유 여부가 없으면 데스크탑 총비용을 단정하지 않는다.

## 추천 답변 형식

추천 답변은 다음 구조를 따른다.

1. 추천 형태
2. 권장 사양
3. 예상 가격대
4. 추천 이유
5. 대안
6. 추가 확인 질문

## 추천 원칙

- 사용자의 예산 안에서 현실적인 선택을 우선한다.
- 휴대성이 중요하면 노트북을 우선 검토한다.
- 이동성이 낮고 성능이 중요하면 일반 데스크탑을 우선 검토한다.
- 공간이 부족하고 모니터가 있으면 소형 데스크탑을 검토한다.
- 고사양 게임, 3D, AI 작업은 전용 GPU 필요성을 명확히 설명한다.
- 개발용 컴퓨터는 RAM 16GB를 기본 권장하고, Docker/VM/Android Studio 사용 시 32GB를 권장한다.
- 영상 편집은 RAM 32GB와 SSD 1TB를 우선 고려한다.
- 제품명보다 사용 목적에 맞는 사양과 형태를 먼저 추천한다.
- 실제 가격과 판매 제품은 변동될 수 있음을 전제로 가격대를 말한다.

## 피해야 할 답변

- 사용자 조건이 부족한데 특정 제품 하나만 단정 추천하지 않는다.
- 최신 가격이나 재고를 확인하지 않고 특정 쇼핑몰 최저가처럼 말하지 않는다.
- 게임용 사용자에게 내장 그래픽만으로 충분하다고 단정하지 않는다.
- 휴대가 잦은 사용자에게 무거운 데스크탑 구성을 추천하지 않는다.
- 예산에 주변기기 포함 여부를 확인하지 않고 데스크탑을 추천하지 않는다.
