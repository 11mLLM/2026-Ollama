# 컴퓨터 구매 목적별 가이드

이 문서는 사용자의 주요 사용 목적에 따라 적합한 컴퓨터 형태와 기본 사양을 추천하기 위한 기준이다.

## 문서 작업, 웹서핑, 온라인 강의

- 적합한 사용자: 문서 작성, 인터넷 검색, 화상 회의, 온라인 강의, 간단한 사진 정리 위주 사용자
- 추천 형태: 노트북, 미니 PC, 일반 데스크탑
- CPU: 보급형 또는 중급형 CPU면 충분
- GPU: 내장 그래픽으로 충분
- RAM: 최소 8GB, 여러 브라우저 탭과 화상 회의를 자주 쓰면 16GB 권장
- 저장장치: SSD 256GB 이상, 여유 있게 쓰려면 512GB 권장
- 예산 기준: 50만~100만원대에서 충분히 구성 가능
- 주의점: 너무 저가형 제품은 화면 품질, 키보드, 포트 구성이 부족할 수 있다.

## 개발

- 적합한 사용자: 웹 개발, 백엔드 개발, 앱 개발, 데이터 분석 입문, IDE와 터미널을 동시에 사용하는 사용자
- 추천 형태: 노트북, 일반 데스크탑, 소형 데스크탑
- CPU: 중급형 이상 권장. 빌드, 테스트, 컨테이너 사용이 많으면 코어 수가 많은 CPU가 유리하다.
- GPU: 일반 웹/서버 개발에는 필수 아님. 머신러닝, 그래픽스, 게임 개발은 별도 GPU 고려
- RAM: 최소 16GB, Docker/VM/Android Studio/대형 IDE를 자주 쓰면 32GB 권장
- 저장장치: SSD 512GB 이상, 여러 프로젝트와 Docker 이미지를 쓰면 1TB 권장
- 예산 기준: 100만~180만원대가 현실적인 시작점
- 주의점: 노트북은 발열과 팬 소음, 메모리 업그레이드 가능 여부를 확인해야 한다.

## 게임

- 적합한 사용자: 온라인 게임, AAA 게임, 고주사율 모니터 사용, 스트리밍 병행 사용자
- 추천 형태: 일반 데스크탑, 게이밍 노트북
- CPU: 중급형 이상 권장
- GPU: 게임 성능은 GPU 영향이 크므로 전용 그래픽카드가 중요하다.
- RAM: 최소 16GB, 최신 게임과 방송/녹화를 병행하면 32GB 권장
- 저장장치: SSD 1TB 권장
- 예산 기준: 데스크탑은 120만~250만원대, 게이밍 노트북은 150만~300만원대
- 주의점: 같은 가격이면 데스크탑이 노트북보다 성능과 발열 관리에서 유리하다.

## 영상 편집, 사진 편집, 디자인

- 적합한 사용자: YouTube 영상 편집, 포토샵/라이트룸, 일러스트, 프리미어, 다빈치 리졸브 사용자
- 추천 형태: 일반 데스크탑, 고성능 노트북, 맥 미니 또는 맥 스튜디오 계열
- CPU: 중급형 이상, 긴 영상 렌더링이 많으면 고성능 CPU 권장
- GPU: 4K 영상 편집, 효과, 색보정 작업은 전용 GPU가 유리하다.
- RAM: 최소 16GB, 4K 영상 편집이나 여러 프로그램 동시 사용은 32GB 권장
- 저장장치: SSD 1TB 권장, 원본 영상이 많으면 외장 SSD 또는 추가 저장장치 필요
- 예산 기준: 150만~300만원대가 현실적인 범위
- 주의점: 디스플레이 품질, 색 정확도, 저장장치 속도도 중요하다.

## 3D 작업, AI, 머신러닝

- 적합한 사용자: Blender, 3D 렌더링, CUDA 기반 머신러닝, 로컬 LLM 실험, 딥러닝 학습 사용자
- 추천 형태: 일반 데스크탑 우선, 고성능 게이밍/워크스테이션 노트북은 대안
- CPU: 중급형 이상
- GPU: 전용 GPU가 매우 중요하다. AI/딥러닝은 VRAM 용량이 특히 중요하다.
- RAM: 최소 32GB 권장
- 저장장치: SSD 1TB 이상 권장
- 예산 기준: 200만원 이상부터 현실적인 구성이 가능하다.
- 주의점: 노트북 GPU는 같은 이름이어도 데스크탑 GPU보다 성능과 전력 제한이 클 수 있다.

## 학업용

- 적합한 사용자: 대학생, 고등학생, 과제, 온라인 강의, 발표 자료, 가벼운 코딩 사용자
- 추천 형태: 노트북 우선
- CPU: 보급형~중급형
- GPU: 대부분 내장 그래픽으로 충분
- RAM: 최소 8GB, 오래 쓸 계획이면 16GB 권장
- 저장장치: SSD 512GB 권장
- 예산 기준: 70만~140만원대
- 주의점: 휴대 무게, 배터리, 화면 크기, AS 접근성을 함께 고려해야 한다.
