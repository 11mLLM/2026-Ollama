# 예산대별 추천 가이드

이 문서는 예산에 따른 현실적인 컴퓨터 구성을 설명한다. 가격은 시장 상황에 따라 달라질 수 있으므로 절대값이 아니라 판단 기준으로 사용한다.

## 50만원 이하

- 추천 대상: 매우 가벼운 문서 작업, 웹서핑, 온라인 강의
- 추천 형태: 보급형 노트북, 중고 데스크탑, 미니 PC
- 기대 사양: 보급형 CPU, RAM 8GB, SSD 256GB~512GB
- 주의점: 오래 쓸 메인 컴퓨터로는 성능과 내구성 한계가 있을 수 있다.
- 추천 판단: 예산이 가장 중요하고 작업이 가벼울 때만 추천한다.

## 50만~100만원

- 추천 대상: 학생, 사무용, 가벼운 개발 입문, 일반 가정용
- 추천 형태: 노트북, 미니 PC, 일반 데스크탑
- 기대 사양: 보급형~중급형 CPU, RAM 8GB~16GB, SSD 512GB
- 주의점: 게임, 영상 편집, AI 작업에는 부족할 수 있다.
- 추천 판단: 휴대성이 필요하면 노트북, 모니터가 이미 있으면 미니 PC나 데스크탑이 유리하다.

## 100만~150만원

- 추천 대상: 개발, 학업, 일반 생산성, 가벼운 사진/영상 편집
- 추천 형태: 중급 노트북, 소형 데스크탑, 일반 데스크탑
- 기대 사양: 중급형 CPU, RAM 16GB, SSD 512GB~1TB
- GPU: 일반 작업은 내장 그래픽 가능, 게임이나 영상 편집은 보급형 전용 GPU 고려
- 추천 판단: 가장 균형 잡힌 예산대이며 개발용 첫 컴퓨터로 적합하다.

## 150만~250만원

- 추천 대상: 본격적인 개발, 게임, 영상 편집, 디자인, 오래 쓸 메인 컴퓨터
- 추천 형태: 고성능 노트북, 게이밍 데스크탑, 성능 좋은 소형 데스크탑
- 기대 사양: 중상급 CPU, RAM 16GB~32GB, SSD 1TB
- GPU: 게임, 영상 편집, 3D 작업은 전용 GPU 권장
- 추천 판단: 성능과 휴대성 중 무엇이 더 중요한지 먼저 정해야 한다.

## 250만원 이상

- 추천 대상: 고사양 게임, 4K 영상 편집, 3D 렌더링, AI/머신러닝, 전문 작업
- 추천 형태: 고성능 데스크탑, 워크스테이션, 크리에이터 노트북
- 기대 사양: 고성능 CPU, RAM 32GB 이상, SSD 1TB 이상, 고성능 전용 GPU
- 주의점: 고성능 노트북은 발열, 소음, 무게, 어댑터 크기를 반드시 고려해야 한다.
- 추천 판단: 이동성이 꼭 필요하지 않다면 데스크탑이 성능과 유지보수 면에서 유리하다.

## 예산 배분 기준

- 문서/웹 중심: CPU와 RAM을 적정 수준으로 맞추고 과한 GPU 비용을 피한다.
- 개발 중심: CPU, RAM, SSD 용량에 우선 투자한다.
- 게임 중심: GPU에 가장 큰 비중을 둔다.
- 영상 편집 중심: CPU, GPU, RAM, SSD를 균형 있게 본다.
- AI/3D 중심: GPU와 VRAM, RAM 용량에 우선 투자한다.
- 노트북 구매: 성능뿐 아니라 화면, 배터리, 무게, 키보드, 포트, AS를 함께 본다.
