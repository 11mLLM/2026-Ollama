# 운영체제와 생태계 선택 가이드

이 문서는 Windows, macOS, Linux 환경 선택 기준을 설명한다.

## Windows

- 장점: 게임 호환성이 좋고 선택 가능한 제품 종류가 가장 많다.
- 장점: 대부분의 업무용 소프트웨어와 주변기기 호환성이 좋다.
- 장점: 같은 예산에서 다양한 노트북과 데스크탑 구성이 가능하다.
- 단점: 제조사와 제품에 따라 품질 차이가 크다.
- 적합한 사용자: 게임, 일반 사무, 학업, Windows 전용 프로그램 사용자, 다양한 가격대에서 고르고 싶은 사용자

## macOS

- 장점: Apple 생태계와 연동이 좋고 노트북 배터리 효율이 우수한 편이다.
- 장점: 개발, 디자인, 영상 편집에서 선호하는 사용자가 많다.
- 장점: 맥 미니는 모니터가 이미 있는 사용자에게 공간 효율이 좋다.
- 단점: 게임 호환성이 제한적이다.
- 단점: 구매 후 RAM과 저장장치 업그레이드가 어렵거나 불가능하다.
- 단점: 같은 저장장치/RAM 용량으로 올릴 때 비용이 크게 증가할 수 있다.
- 적합한 사용자: iPhone/iPad 사용자, macOS 선호 개발자, 조용한 소형 데스크탑을 원하는 사용자, Final Cut Pro 사용자

## Linux

- 장점: 서버 개발, 오픈소스 개발, 터미널 중심 작업에 좋다.
- 장점: 개발 환경을 세밀하게 제어하기 쉽다.
- 단점: 일부 상용 소프트웨어, 게임, 주변기기 호환성 문제가 있을 수 있다.
- 적합한 사용자: 백엔드 개발자, 인프라/DevOps 학습자, Linux 환경을 직접 관리할 수 있는 사용자

## 선택 기준

- 게임이 중요하면 Windows를 우선 고려한다.
- iPhone, iPad, AirDrop, iCloud 연동이 중요하면 macOS가 편하다.
- 백엔드 개발과 서버 환경 학습이 중심이면 Windows + WSL 또는 Linux를 고려한다.
- 영상 편집은 사용하는 프로그램에 따라 Windows와 macOS 모두 가능하다.
- OS 선호가 없으면 예산, 이동성, 성능, AS 기준을 먼저 결정한다.
