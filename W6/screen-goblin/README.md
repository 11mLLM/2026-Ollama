# Screen Goblin — 참견쟁이 훔쳐보개

화면 구석에 사는 **시니컬 팩폭 고양이 '냥차장'**이 주기적으로 스크린샷을 몰래 보고,
지금 뭘 하는지 파악해 상황 맞춤 드립을 말풍선으로 친다.
**모든 추론이 로컬(Ollama)에서 돌아가므로 화면이 클라우드로 새나가지 않는다.**

## 핵심 설계 — 눈과 입의 분리

```
[20초마다 스크린샷] → [눈: moondream] → [입: qwen2.5:7b] → [오버레이: 말풍선 + 고양이 표정]
   mss 캡처·축소        화면을 영어로 묘사     성격+기억 입혀 한국어 드립    PySide6 투명 윈도우
```

- moondream(1.7B): 화면을 사실 그대로 한 문장으로 묘사하는 "눈"
- qwen2.5:7b: 묘사 + 최근 관찰 3개를 받아 성격을 입힌 드립을 만드는 "입"
- 입 모델만 바꾸면 캐릭터 성격이 통째로 바뀐다

## 숨은 기능 — 막힘 감지

같은 화면이 3회 연속 반복되면(예: 같은 에러로 헤맴) 톤이 **드립 → 진짜 도움 넛지**로 전환된다.

## 사전 준비 (1회)

```bash
ollama pull moondream
ollama pull qwen2.5:7b
```

## 화면 기록 권한 (필수!)

macOS는 화면 기록 권한이 없으면 **앱 창은 안 잡히고 바탕화면만** 캡처된다.

1. 터미널에서 `python -W ignore selfcheck.py` 실행
2. `/tmp/screen_goblin_check.png` 를 열어 확인
   - 앱 창이 보이면 → 정상
   - 바탕화면만 보이면 → 아래 권한 설정 필요
3. **시스템 설정 > 개인정보 보호 및 보안 > 화면 기록** 에서 터미널 앱(Terminal/iTerm/VS Code 등) 켜기
4. **터미널 앱을 완전히 종료 후 다시 실행** (재시작해야 권한 적용됨)

## 실행

```bash
./run.sh
# 또는
source .venv/bin/activate && python -W ignore main.py
```

## 단축키 / 조작

- 더블클릭: 지금 즉시 한 번 관찰 (발표용 수동 트리거)
- 드래그: 고양이 위치 이동
- Space: 일시정지 / 재개
- L: 증거 로그 패널 토글 (스크린샷→인식→코멘트 파이프라인 가시화)
- T: 즉시 관찰
- Q: 종료

## 표정(mood)

평온 😼 / 어이없음 🙀 / 질림 😾 / 감탄 😻 / 걱정 🐱

## 튜닝 포인트 (config.py)

- `CAPTURE_INTERVAL_MS`: 캡처 주기 (기본 20초)
- `VISION_MODEL` / `PERSONA_MODEL`: 모델 교체 (눈을 `llama3.2-vision:11b`로 바꾸면 더 정확, 더 느림)
- `STUCK_REPEAT_COUNT` / `STUCK_SIMILARITY_THRESHOLD`: 막힘 감지 민감도

## 발표 시나리오 (3분)

1. 고양이를 띄우고 유튜브를 연다 → 드립
2. 코드 에디터로 전환, 에러 화면을 유지 → 드립이 도움 넛지로 변신 (반전)
3. `L`로 증거 로그를 켜고 `스크린샷 → moondream → qwen2.5` 파이프라인 설명
4. 와이파이를 끄고도 동작 → "로컬이라 화면 다 봐도 안 새나갑니다" 마무리
