# VS Code 단축키 가이드

- 기능: 멀티 커서 (여러 줄 동시 선택)
  - Mac: Cmd + Option + Down/Up
  - Windows: Ctrl + Alt + Down/Up
- 기능: 터미널 열기/닫기
  - Mac: Cmd + `
  - Windows: Ctrl + `
- 기능: 사이드바 보이기/숨기기
  - Mac: Cmd + B
  - Windows: Ctrl + B

# Figma 단축키 가이드

- 기능: 오토 레이아웃(Auto Layout) 적용
  - Mac: Shift + A
  - Windows: Shift + A
- 기능: 구성 요소(Component) 만들기
  - Mac: Cmd + Option + K
  - Windows: Ctrl + Alt + K
- 기능: 레이어 이름 변경
  - Mac: Cmd + R
  - Windows: Ctrl + R

# Chrome 단축키 가이드

- 기능: 시크릿 창 열기
  - Mac: Cmd + Shift + N
  - Windows: Ctrl + Shift + N
- 기능: 닫은 탭 다시 열기
  - Mac: Cmd + Shift + T
  - Windows: Ctrl + Shift + T

# IntelliJ 단축키 가이드

- 기능: 파일 또는 클래스 전체 검색
  - Mac: Shift + Shift (Double Shift)
  - Windows: Shift + Shift (Double Shift)
- 기능: 스마트 코드 자동 완성
  - Mac: Ctrl + Space
  - Windows: Ctrl + Space
- 기능: 코드 자동 정렬 (Reformat Code)
  - Mac: Cmd + Option + L
  - Windows: Ctrl + Alt + L

# MS Office 단축키 가이드 (Excel, Word, PPT 공통)

- 기능: 서식만 복사하기
  - Mac: Cmd + Shift + C
  - Windows: Ctrl + Shift + C
- 기능: 서식만 붙여넣기
  - Mac: Cmd + Shift + V
  - Windows: Ctrl + Shift + V
- 기능: 다른 이름으로 저장하기
  - Mac: Cmd + Shift + S
  - Windows: F12
