# PR 템플릿: 기타 변경

### Description
- 이번 PR에서 어떤 문서/설정/기타 변경을 했는지 작성하세요.

### Motivation
- 왜 이 변경이 필요한지 작성하세요.
- 어떤 영향이 있는지 설명하세요.

### Summary of Changes
- 변경한 파일/설정/문서를 나열하세요.
- 예: `README.md` 업데이트, `commitlint` 규칙 추가, 템플릿 폴더 재구성

### Noteworthy Choices
- 선택한 구성 방식이나 변경 이유를 기술하세요.
- 예: 기존 `.github` 설정 대신 루트에 템플릿 파일 배치

### Example Usage
- 변경 후 사용 방식 또는 검증 방법을 작성하세요.
- 예: `feature_pr.md`를 참고하여 PR 작성

### Checklist
- [ ] 변경 사항 검토 완료
- [ ] 문서/설정 적용 확인
- [ ] 관련 이슈 번호 기재
